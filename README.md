# Sol a Sol

App minimalista de finanzas personales: lo libre del mes, gastos fijos, cierre del día con racha y fondo de emergencia. Se instala en el celular.

**App:** https://renzomoran9.github.io/Sol-a-Sol/

## Cómo está armada

- `index.html`, `sw.js`, `manifest.json`, íconos: la app (PWA). Los datos se guardan solo en el celular.
- `.github/workflows/publicar.yml`: publica la app en GitHub Pages en cada cambio a `main`.

## Instalar en el celular

Abre https://renzomoran9.github.io/Sol-a-Sol/ en el celular.

- **Android (Chrome):** menú ⋮ → *Instalar app*.
- **iPhone (Safari):** Compartir → *Agregar a inicio*.
